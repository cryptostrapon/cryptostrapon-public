# Security policy

This repository contains documentation only, no executable code and no secrets.

## Reporting a problem

- Use GitHub private vulnerability reporting (Security tab, "Report a vulnerability").
- Or email cryptostrapon@proton.me.

Do not include seed phrases, private keys or passwords in any report.

## Scope

The detector itself runs at https://cryptostrapon.com and is not open source. Security issues with the website can be reported through the same channels.
